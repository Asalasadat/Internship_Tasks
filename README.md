# AI/ML Internship - Week 1






## Day 4 — Pandas: Tabular Data

In this day, I learned how to work with tabular data using Pandas, the most widely used library for data analysis in Python. I practiced loading datasets, exploring their structure, cleaning data, filtering records, and performing group-based analysis.

Topics covered:
- Introduction to Pandas Series and DataFrames
- Loading and inspecting datasets using `read_csv`, `head`, `info`, and `describe`
- Selecting columns and filtering rows with boolean indexing, `.loc`, and `.iloc`
- Data cleaning techniques, including handling missing values, duplicates, and data type conversion
- Grouping and aggregating data using `groupby()` and `agg()`

**Tools:** Pandas, Jupyter Notebook


## Day 5 — Matplotlib & Week 1 Mini-Notebook

In this day, I learned how to visualize data using Matplotlib and combine NumPy, Pandas, and Matplotlib in a complete data analysis workflow. I practiced creating different types of plots, comparing data using subplots, and building a mini-notebook following the data science pipeline: **load → process → visualize**.

Topics covered:
- Importance of data visualization for exploration and communication
- Matplotlib basics: creating plots, adding labels, titles, and displaying figures
- Creating different visualization types:
  - Line plots for trends over time
  - Scatter plots for relationships between variables
  - Bar charts for category comparisons
  - Histograms for understanding data distributions
- Using subplots for comparing multiple visualizations
- Building an integrated notebook using NumPy, Pandas, and Matplotlib
- Documenting analysis and visual findings using Markdown cells
- Version control of notebooks using Git & GitHub

**Tools:** Matplotlib, Pandas, NumPy, Jupyter Notebook, Git & GitHub
